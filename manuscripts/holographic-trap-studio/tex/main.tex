\begin{abstract}
A phase-only spatial light modulator (SLM) in the pupil of a microscope objective can form hundreds to thousands of optical traps at once, but only if the phase pattern it displays is computed well: the pattern fixes how much light reaches the traps, how equal the traps are, where stray light goes, how the pattern survives a real device, and how fast it can be recomputed when traps move. The largest published neutral-atom array holds \execAtoms{} atoms with a trap-depth spread of \execSpread{} percent, so the choice of hologram method is a decision of scale. DinHot is an open studio that runs \nLadder{} methods (\nPublished{} published ones and \nProposed{} proposed here) on the same task, with the same seeds, metrics and a scalar Fourier model with a device model of quantization, pixel crosstalk, pixel aperture and flicker, in Python as the reference and in a TypeScript port that runs live in a browser. The report documents the model, the twelve data contracts, the pipeline, every method with its equations, parameters and acceptance test, \nCases{} cases from a $3\times3$ array to a disordered array of \nDisordered{} traps and shaped potentials, a benchmark of \benchRows{} rows, and two learned models. Phase-fixed weighted Gerchberg--Saxton leaves a median relative standard deviation of \medSigmaMseven{} percent against \medSigmaMfour{} percent for plain Gerchberg--Saxton over \nBothFourSeven{} cases, but its published freeze index stalls on a crowded array of this grid. Three of the proposed methods meet their criteria within a measured scope (a device-aware weighted update, a flicker-bounded phase-continuous sequence and an efficiency--uniformity front), one meets a narrowed criterion (an aberration-robust hologram) and one is refuted by a control (a learned warm start). A network trained on three-plane volumes beats its baseline at equal wall-clock on all \cghN{} held-out volumes (median accuracy ratio \cghMed{}), whereas its two-dimensional counterpart ties with Gerchberg--Saxton (ratio \cghTwoDMed{}). The model is a scalar Fourier model of a simulated device, not a calibrated instrument.
\end{abstract}

\noindent\textbf{Keywords:} holographic optical tweezers, spatial light modulator, weighted Gerchberg--Saxton, pixel crosstalk, neutral-atom arrays, hologram benchmarking, learned holography.

\section{Methods}\label{sec:methods}

The methods are described in the order of the design document's ladder: the published methods M01 to M19 and then the methods proposed here, B1 to B5; the ids are the engine's compact labels, and each subsection names its method. Every method is a module with a specification and a run function behind the interface of Section~\ref{sec:arch-engine}: it takes the optical setup, a target of traps or of a shaped field, an optional device, a budget, the portable random generator and an optional starting phase, and returns the phase, a history of the metrics, the trap fields and a metadata record. The forward model of Eqs.~\eqref{eq:delay} and~\eqref{eq:field} and the metrics of Eq.~\eqref{eq:metrics} are shared by all of them, and the scorer recomputes the scores from the returned phase, so that no method grades itself. Each subsection gives the role of the method and its source, the equations, the parameters with their values and how they were chosen, the computational complexity, the lane, the acceptance criterion with the gate that measures it and the measurement of this report, and the implementation module. The measured text of each method is generated by the acceptance script and not typed here. The keyword defaults are read from the signature of each run function and are listed in Table~\ref{tab:defaults}; the acceptance criteria are in Table~\ref{tab:ladder}.
